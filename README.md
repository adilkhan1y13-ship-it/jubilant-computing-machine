# Last Zone — Original Battle Royale Prototype

A small, original browser game prototype inspired by the battle-royale genre. It is **not a Free Fire clone** and uses original simple graphics.

## Run
1. Extract the ZIP.
2. Open `index.html` in a modern browser, or upload the folder to a static website host.
3. Press **START MATCH**.

## Controls
- Desktop: WASD/arrow keys to move, mouse to aim, click or Space to fire.
- Mobile: use the MOVE pad and FIRE button.
- The prototype includes enemy bots, a basic shrinking safe zone, health, kills, and an auto-aim/headshot-style assist mechanic.

## Important
This is a lightweight 2D prototype, not a production 3D online game. It does not connect to Free Fire, use Free Fire assets, or modify any other game. The auto-aim mechanic only works inside this standalone prototype.
